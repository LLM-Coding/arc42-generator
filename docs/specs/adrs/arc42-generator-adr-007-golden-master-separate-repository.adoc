[[ADR-007]]
= ADR-007: The Golden Master stays a separate repository

*Status:* accepted

*Context:* content and build logic have different audiences. Translators must not need build
knowledge; release engineers must not wade through translations.

*Decision:* two repositories. This one holds build logic and configuration, `arc42-template`
holds only content, consumed as a Git submodule
(`docs/arc42_build_process_requirements.md:86-104`, `.gitmodules:1-6`).

*Consequences:* clean separation of concerns, and the same build can serve further templates such
as req42. The price is submodule handling in every workflow, and a distribution directory that
lives inside the content repository, so releasing means committing there
(`buildconfig.groovy:38`, <<R-7>>).
