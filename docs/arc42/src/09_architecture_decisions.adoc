== Architecture Decisions

Seven decisions shape this build. Each is recorded in Nygard form as its own file under
`docs/specs/adrs/` and scored with a three-point Pugh matrix (`+1` better, `0` equal, `-1` worse)
against the quality goals of chapter 1.2 and the maintenance effort. The baseline column is the
option that was in place at the time.
